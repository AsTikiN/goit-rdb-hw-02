# goit-rdb-hw-02

Домашнє завдання до теми 2: нормалізація таблиці замовлень (1НФ–3НФ), ER-діаграма та порожня схема MySQL.

## Структура

| Файл | Опис |
| --- | --- |
| `normalization.md` | Етапи 1–3, таблиці та функціональні залежності |
| `p1_1nf.png` … `p5_schema.png` | Скріни етапів (префікси `p1_`–`p5_`) |
| `p4_er_diagram.svg` | ER у векторі |
| `p5_schema.sql` | Створення таблиць без даних |
| `sql_code.txt` | Текст SQL для здачі |
| `LMS_SUBMISSION.md` | Як прикріпити роботу в LMS |

## Локальна перевірка

```bash
mysql -u root < p5_schema.sql
```

У MySQL Workbench відкрийте схему `goit_rdb_hw_02` і переконайтесь, що таблиці порожні.
